# HourBlock

Local-first billable time tracking with a live meter, editable client rates, monthly totals, and CSV export.

## Features

- Start and stop live billable sessions with quarter-hour rounding.
- Add manual entries for missed work.
- Keep client hourly rates in browser local storage.
- Review monthly billable totals and estimated revenue.
- Export the selected month to CSV for all clients or one client.

## Privacy

HourBlock stores entries, active sessions, and client rates in browser local storage. The repository does not include personal client configuration, environment files, deployment settings, or generated build output.
